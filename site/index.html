Rounded bowls, confident curves and a little personality in every word.

AT-KPN brings English, Kannada, Hindi, Marathi, Malayalam, Tamil, Telugu and Bengali into one display family. Use Light for a quieter voice, Regular for a familiar one, and Bold when you have something to say.

Built on Baloo 2 by Ek Type, with AT-KPN drawings, proportion adjustments and refined terminals. The font software is shared under the SIL Open Font License 1.1.

Explore the source on GitHub

A few useful details.

License & commercial use+

AT-KPN is free to use in personal and commercial work. You can modify and redistribute the font software under the SIL Open Font License 1.1. Keep the license and copyright notices with redistributed fonts. Font files cannot be sold on their own.

Installing the desktop fonts+

Download TTF or OTF, unzip the folder, then open a font file and choose Install. Pick one of these formats for each family; both contain the same design. Restart your design app if the family does not appear immediately. Look for “AT-KPN” or a language family such as “AT-KPN Kannada”.

Using AT-KPN on the web+

Download the Web kit. Keep its fonts/ folder beside AT-KPN.css, and link the stylesheet. The combined family supports all eight languages.

HTML + CSS
<link rel="stylesheet" href="AT-KPN.css">

body {
  font-family: 'AT-KPN', sans-serif;
  font-weight: 400;
}
Contributing & reporting a glyph issue+

Editable sources and build tools are on GitHub. If a character or conjunct needs attention, open an issue with the language, text, weight and application. Native-language feedback is welcome as the family develops.
