06 — About

About the typeface

Designed by AT.

Soft corners, open shapes and an even weight across seven scripts.

AT-KPN is one family for English and seven Indian languages. Every script shares the same rounded stroke endings, open counters and stroke weight, so mixed-language text sits together comfortably.

It is a display family, made for headlines, signage, packaging and interfaces at larger sizes. The Indian scripts use OpenType shaping for conjuncts and vowel signs, and Malayalam includes an optional stacked form.

License and commercial use+

AT-KPN is free to use in personal and commercial work. You may modify and redistribute the fonts under the SIL Open Font License 1.1. Keep the license file and its copyright notices with any copy you pass on. The fonts cannot be sold on their own.

Installing on a computer+

Download TTF or OTF, unzip the folder, open a font file and choose Install. Use one format per family; both hold the same design. If the family does not appear, restart your design app. Look for “AT-KPN”, or a language family such as “AT-KPN Kannada”.

Using it on a website+

Download the Web kit, keep its fonts/ folder beside AT-KPN.css, and link the stylesheet. The combined family covers all eight languages.

HTML + CSS
<link rel="stylesheet" href="AT-KPN.css">

body {
  font-family: 'AT-KPN', sans-serif;
  font-weight: 400;
}
Malayalam stacked form+

Malayalam sets the conjunct സ്ക side by side by default. Turn on OpenType stylistic set 1 (ss01) for the stacked form. You can try it in the tester by choosing Malayalam.

Reporting a problem with a letter+

If a character or conjunct looks wrong, open an issue on GitHub with the language, the text, the weight and the app you used. Feedback from native readers is especially welcome.
